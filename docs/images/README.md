# Screenshots

The README expects three files in this directory. Until they exist, the images on the README will show as broken.

| File | Screen | What to capture |
| --- | --- | --- |
| `home.png` | Home | The situation list, both rows visible |
| `drill.png` | Drill | Mid-sentence: two or three tiles placed, the rest of the bank showing. Best taken after a second miss so the grammar note is on screen |
| `complete.png` | Set complete | The first-try score |

Capture at a phone viewport — 390 × 844 (iPhone 14) in DevTools device mode — so the three sit at the same scale side by side in the README. `npm run dev`, then use the browser's own screenshot capture rather than an OS one, to avoid the surrounding chrome.

Delete this file once the screenshots are in.
